# Knowl v0.8.1

This patch release restores idempotent Git source synchronization when an
unchanged blob is encountered through a newer commit URL, and updates
OpenTelemetry dependencies to resolve GO-2026-6974.

## Git raw replay recovery

- Reuse the first accepted raw record when source identity, blob revision, and
  content digest match but the commit-derived original URI has changed.
- Preserve the original accepted URI and immutable manifest without rewriting
  raw evidence.
- Continue rejecting changed content, source identity, document identity, and
  invalid revision provenance with their existing typed errors.
- Recover synchronization that stopped after raw acceptance but before source
  state and catalog publication.

## Security

- Update the affected OpenTelemetry API modules to v1.47.0, which fixes
  GO-2026-6974, and align the ADK dependency with that API generation.
- Update `golang.org/x/net` to v0.62.0, which fixes GO-2026-6860 and
  GO-2026-6866 in HTML parsing and rendering paths used by the Web UI.

No database or workspace migration is required. Existing configurations remain
compatible.

## Installation

After publication, run from a local project root:

```bash
npx --yes @baldaworks/knowl@0.8.1 setup codex
```

See [publishing](../publishing.md) for release verification and distribution
details.
