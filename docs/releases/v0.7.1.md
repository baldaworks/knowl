# Knowl v0.7.1

This patch release stabilizes the browser test harness used to verify Knowl's
Web UI. Application behavior and the durable storage schema are unchanged
from v0.7.0.

## Fix

- Keep a pass-through Playwright route active while one-shot fault routes
  expire. This prevents a Chromium interception shutdown race from stranding
  the UI's immediate recovery request after `snapshot_changed`.
- Preserve fault injection, UI assertions, security checks, and existing
  deadlines. The fix adds no retries or timeout increases and changes no
  production UI code.
- Align the Codex plugin, MCP launcher, installation guidance, and native npm
  package release contract at `0.7.1`.

## Installation

After publication, run from a local project root:

```bash
npx --yes @baldaworks/knowl@0.7.1 setup codex
```

Native npm packages cover macOS x64/arm64, Linux x64/arm64, and Windows x64.
The container remains available for Linux amd64 and arm64.

## Upgrade

No additional storage migration or configuration change is introduced by this
patch. When upgrading from a version older than v0.7.0, follow the
[v0.7.0 upgrade guidance](v0.7.0.md#upgrade-and-recovery), including its source
retirement and downgrade cautions.

See [publishing](../publishing.md) for release verification and distribution
details.
