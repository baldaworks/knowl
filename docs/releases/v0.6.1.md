# Knowl v0.6.1

This release prepares the local Codex plugin and five native CLI packages for
publication through npm trusted publishing. It includes the changes accumulated
since v0.5.0; the v0.6.0 publication stopped before uploading artifacts because
its workflow required a token.

## Changes

- npm publication uses GitHub Actions OIDC through Omnidist. The release job
  requires no stored npm publication token. Each npm package must first have
  its trusted publisher registered for `baldaworks/knowl`, workflow `release.yml`.
- The local Codex plugin supplies `setup` and `run` skills and host-owned MCP
  stdio integration. Plugin, launcher, and native packages use version `0.6.1`.
- The optional operator Web UI provides knowledge browsing, search, processing
  history, source status, and saved-source inspection.
- Hybrid search covers complete pages, preserves structured Markdown and OKF
  section context, and reuses authenticated embeddings when rebuilding
  SQLite or PostgreSQL projections.
- Generated wiki navigation uses portable relative Markdown links. Maintenance
  validates generated navigation, exports preflight OKF documents, and graph
  extraction excludes literal code and image descriptions.
- The repository wiki was regenerated with the configured maintainer and
  independently reviewed. Existing raw revisions and log history were preserved.

## Installation

After the npm packages have been published, run from a local project root:

```bash
npx --yes @baldaworks/knowl@0.6.1 setup codex
```

Native packages cover macOS x64/arm64, Linux x64/arm64, and Windows x64.
Maintenance requires a configured maintainer provider. The plugin supports local
Codex projects on local filesystems; existing explicit HTTP sidecar and embedded
Go deployments remain supported.

## Release verification

Publication remains gated on module and OpenAPI checks, the complete race-test
suite, vulnerability scanning, both linters, PostgreSQL integration, persistent
volume container smoke tests, and verified native npm artifacts. The workflow
publishes the multi-platform container and records its immutable digest.

See [publishing](../publishing.md) for the one-time npm trust setup and
[local Codex setup](../local-codex.md) for installation details.
