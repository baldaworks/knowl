# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately through [GitHub Security
Advisories](https://github.com/baldaworks/knowl/security/advisories/new). Do
not open a public issue or disclose the vulnerability until a fix is available.

Include reproduction steps, affected versions or commits, impact, and any
mitigations you know of. Maintainers will acknowledge the report and coordinate
disclosure through the advisory; no response-time guarantee is made.

## Supported versions

The current `main` development line is supported. There are no separately
maintained release branches yet.
